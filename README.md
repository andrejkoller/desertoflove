# desert of love

A landscape of longing

An original composition centered around the oud, woven with other Middle Eastern instruments.

Warm, expansive, and quietly intense - music that drifts through heat, distance, and desire.

## Stack

- [Next.js 16](https://nextjs.org) (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- GSAP

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
